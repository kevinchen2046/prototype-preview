# 节拍疯人秀 · Beat Bonkers

Phaser 4 竖屏 HTML5 原型，部署在 Prototype Preview 中供直接试玩。

- 在线试玩： https://kevinchen2046.github.io/prototype-preview/beat-bonkers/
- 9 个微型关卡：点击 × 3、拖拽、按住/松开、快速滑动、双指、摇晃、声音触发。
- 自制 SVG 卡通资产，随节拍脉动；Web Audio 程序合成鼓点。
- 快速预览每关 5 秒；完整节奏每关 15 秒。
- 多人匹配、好友房、排行榜与生产级美术未实现。

Phaser 4 通过 CDN 加载；第一次打开需要联网。摇晃和麦克风仅在对应关卡按需请求权限，桌面端可用模拟操作完成关卡。
