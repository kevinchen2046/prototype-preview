# 节拍疯人秀 · Beat Bonkers

Phaser 4 竖屏 HTML5 原型，部署在 Prototype Preview 中供直接试玩。

- 在线试玩：https://kevinchen2046.github.io/prototype-preview/beat-bonkers/
- 核心循环：垂直跑酷（自由坠落、倒挂攀爬、重力失控）与 9 种荒诞事件交替出现。
- 主跑酷：左右滑动换道躲避障碍；踩准鼓点点击可冲刺并清除附近障碍。
- 事件由前进距离触发，不再将小游戏连续排列成独立关卡。
- 事件包括：追苍蝇、空中踩点自拍、躲老板、拖动安全帽、憋喷嚏、披萨滑动、双指点火、摇醒吸血鬼、长按尖叫。
- 三次生命机会；碰撞和失败事件会消耗生命；完成所有事件后冲向终点线。
- 自制 SVG 卡通资产、动态下落/攀爬场景、按钮按压反馈、成功/失败提示、Web Audio 程序合成节拍。
- 快速预览用于快速验证节奏；完整模式目标约 2 分钟。多人匹配、好友房、排行榜与生产级美术未实现。

Phaser 4 通过 CDN 加载；第一次打开需要联网。移动端摇晃操作支持设备传感器，也可以点击模拟按钮。
