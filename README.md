## 目录约定

```text
index.html                         公共 Demo 导航页
ai-civilization/index.html         AI 文明演化第一章
beat-bonkers/index.html           Phaser 4 九款小游戏接力原型
beat-bonkers/assets/*.svg         自制卡通角色与道具
.github/workflows/pages.yml       GitHub Pages 发布流程
```

只存放允许公开的前端交互原型和相关图片资产，不复制私有仓库的游戏源码、机密文档、凭据或密钥。新增游戏原型后，在根目录 `index.html` 添加入口卡片；推送到 `main` 后由 GitHub Actions 发布。
